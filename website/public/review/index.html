Alba: user-initiated photo transfers

Google Play review evidence for Alba 0.1.1 (1004), recorded on Android 13.

What the recording shows

  1. Select 20 sample items and choose Keep offline.
  2. Open Android notifications. Alba displays Transferring photos, ongoing progress and a Cancel transfers action.
  3. The notification disappears when work finishes. Alba's Activity sheet shows Keep offline · done: 20/20.

Demo boundaries

The recording uses Alba's public demo and bundled sample media. The platform foreground service, notification, batch processing and local original-file cache are real. The original bytes come from local fixtures; this video does not demonstrate Apple authentication or live network transfers. The recording uses a development build from the same source revision as release 1004.

Permission use

On Android 11–13, user-requested original downloads and uploads run through WorkManager's data-sync foreground service. On Android 14 and later, these transfers use user-initiated data-transfer jobs instead. Automatic periodic JPEG backup is separate background work.
